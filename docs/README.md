# مستندات هم‌قدم

هم‌قدم اکنون برنامهٔ فارسی و راست‌به‌چپ کشف و اطلاع‌رسانی رویداد است. خرید و رزرو تازه غیرفعال‌اند؛ [حالت اطلاع‌رسانی](discovery-mode.md) رفتار فعال نسخهٔ فعلی را مشخص می‌کند. این راهنما رفتار کد موجود در همین مخزن را توضیح می‌دهد؛ منبع قراردادهای اجرایی `app/api/`، مدل داده `db/schema.ts` و مهاجرت‌های `drizzle/` است.

نسخهٔ مستندات API پس از استقرار این کد در [hmghadam.com/docs](https://hmghadam.com/docs) و قرارداد قابل دریافت در [hmghadam.com/docs/openapi.json](https://hmghadam.com/docs/openapi.json) قرار می‌گیرد. در توسعه نیز همین مسیرها روی مبدأ محلی کار می‌کنند. این پوشه به‌طور کامل روی وب منتشر نمی‌شود؛ فقط صفحهٔ Swagger و فایل OpenAPI مسیر HTTP دارند.

## محدودهٔ محصول

کاربر می‌تواند رویدادها را ببیند، برگزارکننده یا مجموعه را دنبال کند و رویداد ذخیره کند. خرید تازه فعال نیست؛ وضعیت پرداخت، رسید، بلیت و نظر مرتبط با رزروهای قبلی برای نگهداری سابقه باقی‌اند. میزبان رویداد، ظرفیت، برنامه، سری تاریخ‌ها و سوابق شرکت‌کنندگان را مدیریت می‌کند. مدیر به محتوای سایت، مقالات، پیام تماس و تعدیل نظرات دسترسی دارد.

رزرو رایگان و ورود با رمزِ حساب موجود به سرویس پیامک و پرداخت وابسته نیستند. ورود پیامکی/ثبت‌نام/بازیابی به کاوه‌نگار، پرداخت پولی به زرین‌پال، ایمیل به Resend و Push به تنظیم VAPID و مرورگر سازگار نیاز دارند. ورود Google و Apple، پرداخت‌های دیگر، بازپرداخت خودکار و زبان‌های دیگر در کد فعلی پیاده‌سازی نشده‌اند.

## شواهد طراحی موجود

راهنماهای بالا فارسی هستند. گزارش‌های تاریخی طراحی و آزمون بصری، با متن اصلی خود برای حفظ جزئیات و قابلیت پیگیری نگهداری شده‌اند: [ممیزی Figma](figma-audit.md)، [توکن‌ها و هندسه](design-system.md)، [فهرست اجزا و نگاشت ۵۲ صفحه](component-inventory.md)، [بازبینی RTL](rtl-localization.md)، [گزارش تصویری](visual-qa.md)، [گزارش بررسی‌های قبلی](verification-log.md) و [گالری تصاویر](figma/qa/index.html). نتایج این گزارش‌ها مربوط به اجرای ثبت‌شدهٔ خودشان است، نه تأیید خودکار نسخهٔ فعلی.

همگام‌سازی یک‌طرفهٔ شیت، زمان‌بندی منعطف و worker پایدار Docker در [راهنمای همگام‌سازی رویداد](event-sheet-sync.md) آمده است.

# رابط فارسی، طراحی و دسترس‌پذیری

[فهرست مستندات](README.md)

رابط مصرف‌کننده در `components/evenline/` و توکن‌ها در `design-system/tokens.css` نگهداری می‌شوند. طرح مرجع Evenline با زبان و قواعد دامنهٔ هم‌قدم تطبیق داده شده است. صفحه‌های میزبان، مدیریت و اسکنر همچنان ابزارهای دامنهٔ مستقل خود را دارند.

## زبان و جهت

سند برنامه `lang="fa" dir="rtl"` دارد. متن عمومی در `locales/fa.ts`، متن دامنه/خطا/پنل در `locales/domain-fa.ts` و متن حریم خصوصی در `locales/privacy-fa.ts` است. محتوای قابل ویرایش مانند مقاله و FAQ از دادهٔ واقعی می‌آید. نام فیلدها و اعداد API ترجمه نمی‌شوند.

نمایش زمان با تقویم شمسی و `Asia/Tehran`، ارقام فارسی و قیمت تومان است. URL، ایمیل، کد تأیید، بارکد و QR در محدودهٔ LTR نمایش داده می‌شوند. در CSS تا حد امکان ویژگی‌های منطقی به کار می‌روند؛ عکس، لوگو و جغرافیای نقشه نباید برای RTL آینه شوند. جهت فلش‌ها مستقل تغییر می‌کند.

## طراحی و وضعیت‌ها

قلم IRANSansX از `public/fonts/iransansx/` ارائه می‌شود. رابط مصرف‌کننده برای قاب مرجع ۳۷۵ پیکسل با حاشیهٔ محتوای ۲۴ پیکسل طراحی شده و در عرض کمتر تطبیق می‌یابد. حالت روشن و تیره به کمک نقش‌های رنگی تغییر می‌کند؛ بعضی آثار برند و بلیت رنگ ثابت دارند. تصاویر مرجع Figma در bundle برنامه بارگذاری نمی‌شوند.

حالت loading باید تابع درخواست واقعی باشد. حالت خالی، خرابی نقشه، نبود تصویر، سرویس تنظیم‌نشده و مجوز ردشده حالت‌های واقعی محصول‌اند. برای حساب فاقد تصویر از حروف نام استفاده می‌شود. کنترل ویدیو از رخدادهای HTML media زمان و پیشرفت را می‌گیرد و زمان ساختگی نمایش نمی‌دهد.

منطق مشترک ناوبری در `AppLink`، کنترل OTP در `VerificationCode`، تصویر حساب در `Avatar` و چارچوب عمومی در `EvenlineFrame` قرار دارند. نمایشگر موبایل و پنل‌های مدیریتی یک عرض ثابت مشترک ندارند؛ تغییر CSS باید در هر دو بررسی شود. دارایی CSS اسکنر و نقشه طبق سازگاری نسخهٔ موجود یک‌بار در layout سرور وارد می‌شوند.

## مستندات API

صفحهٔ `/docs` یک سند فارسی مستقل با قلم همان پروژه است. مسیرها، JSON و قطعه‌کدها LTR و شرح‌ها RTL هستند. دارایی Swagger فقط در صفحهٔ مستندات بارگیری می‌شود و وارد صفحهٔ اصلی نمی‌شود. رابط استاندارد Swagger برخی کنترل‌های انگلیسی مانند Execute و Authorize دارد؛ نام گروه‌ها، توضیح API و قرارداد فارسی‌اند.

## بررسی تغییر ظاهری

حداقل در عرض مرجع و عرض کوچک‌تر، هر دو تم، عنوان فارسی بلند، متن ترکیبی فارسی/لاتین، حرکت صفحه‌کلید و حالت خطا بررسی کنید. آزمون نقشه باید ترافیک کاشی را کنترل کند و سرویس عمومی را با مرور خودکار پرتعداد مصرف نکند. شواهد جزئی طرح اصلی در [سیستم طراحی](design-system.md)، [نگاشت اجزا](component-inventory.md)، [RTL](rtl-localization.md) و [گالری](figma/qa/index.html) حفظ شده‌اند.

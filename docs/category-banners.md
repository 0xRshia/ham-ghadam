# بنرهای دسته‌بندی

بنرهای سه‌بعدی ارسالی کاربر در `public/banners` جایگزین الگوهای قبلی صفحهٔ کشف شده‌اند. سایت پنج دسته دارد و هر پنج فایل به موضوع متناظر وصل شده‌اند:

| دسته | تصویر | منبع |
| --- | --- | --- |
| کتاب و گفتگو | `books.png` | `IMG_6466.png` |
| قهوه و کافه | `coffee.png` | `IMG_6467.png` |
| هنر و تجربه | `art.png` | `IMG_6468.png` |
| موسیقی | `music.png` | `IMG_6469.png` |
| بازی و دورهمی | `games.png` | `IMG_6470.png` |

دو فایل اول از ابتدا کانال شفافیت داشتند. پس‌زمینهٔ شطرنجی خارج از قاب رنگی سه فایل آخر با ابزار داخلی `imagegen` حذف شد. دستور ویرایش برای هر فایل: «فقط پس‌زمینهٔ شطرنجی بیرون مستطیل گرد را شفاف کن؛ زمینهٔ رنگی، اشیا، نور، جزئیات و ترکیب داخل بنر حفظ شوند؛ متن یا شیء جدید اضافه نشود».

حاشیهٔ خروجی در ظرف بنر برش نمایشی می‌خورد. عنوان فارسی و شمار رویدادها روی فضای خالی سمت راست قرار می‌گیرند و همچنان از داده‌های سایت می‌آیند. انتخاب هر بنر همان فیلتر دستهٔ قبلی را اعمال می‌کند. تصاویر اصلی ارسالی و فایل‌های قدیمی Figma حذف یا بازنویسی نشده‌اند.

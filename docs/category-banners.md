# بنرهای دسته‌بندی

از ۲۸ اکتبر ۲۰۲۶ هر شش دستهٔ صفحهٔ کشف از مجموعهٔ تصویرسازی سنجاب در `public/banners/squirrel/` استفاده می‌کنند. نام هر فایل همان شناسهٔ دسته است و `components/evenline/explorer.tsx` مسیر را مستقیماً از شناسه می‌سازد. دستهٔ موقت هالووین در صفحهٔ کشف، فیلترها و فرم‌های ساخت رویداد بالاتر از سایر موضوع‌ها قرار دارد:

| دسته | تصویر | فایل ارسالی |
| --- | --- | --- |
| هالووین | `halloween.webp` | `holloween.png` |
| موسیقی | `music.webp` | `image_2026-10-28_12-08-13.png` |
| هنر و تجربه | `art.webp` | `painting.png` |
| کتاب و گفتگو | `books.webp` | `story_book.png` |
| بازی و دورهمی | `games.webp` | `board_game.png` |
| قهوه و کافه | `coffee.webp` | `coffe.png` |

فایل ارسالی `game_or_cards.png` گزینهٔ دوم دستهٔ بازی بود و استفاده نشده است؛ برای جایگزینی کافی است آن را با همان روش به `games.webp` تبدیل و `npm run images:optimize` را اجرا کنید.

همهٔ فایل‌ها ۱۹۸۳ × ۷۹۳ پیکسل، بدون حاشیهٔ شفاف و بدون نوشته‌اند و با Sharp به WebP کیفیت ۸۸ و ابعاد اصلی تبدیل شده‌اند. تصویر با `object-fit: cover` کل ظرف را پر می‌کند؛ قانون‌های برش و کشیدگی مخصوص بنرهای سه‌بعدی قبلی حذف شده‌اند. شخصیت در سمت چپ است و عنوان فارسی و شمار رویدادها روی فضای خالی سمت راست قرار می‌گیرند و همچنان از داده‌های سایت می‌آیند. انتخاب هر بنر همان فیلتر دسته را اعمال می‌کند.

بنرهای سه‌بعدی پیشین (`public/banners/*.png`، `*.webp` و `halloween-v2.webp`) به‌عنوان منبع تاریخی باقی مانده‌اند ولی دیگر در رابط استفاده نمی‌شوند؛ `halloween.png` همچنان فایل آزمون بارگذاری `tests/fast-event-browser.mjs` و راهنمای استقرار است. نسخه‌های بهینهٔ آن‌ها از `public/optimized/` حذف شده‌اند. آیکون دستهٔ هالووین از Ghost کتابخانهٔ نصب‌شدهٔ Lucide گرفته شده و مجوز ISC در خود `public/icons/ghost.svg` آمده است.

شناسهٔ این دسته `halloween` است و در فهرست مشترک دامنه، متن رابط و enumهای قرارداد API ثبت شده است. ساخت و ویرایش رویداد در پنل میزبان و `/fast` از همان اعتبارسنجی مشترک استفاده می‌کنند؛ ستون دستهٔ رویداد متنی است و مهاجرت پایگاه لازم نیست. حذف بعدی این دسته باید با تصمیم دربارهٔ دستهٔ رویدادهای هالووین موجود همراه شود تا ویرایش آن‌ها همچنان معتبر بماند.

کاور رویداد از بنر دسته جداست: کاورهای تازهٔ پیش‌نمایش در `public/images/events` عکس‌های تمام‌صفحه و بدون قاب‌اند؛ جزئیات و دستور اتصال به دادهٔ محلی در [راهنمای کاورها](../public/images/events/README.md) آمده است. بنرهای دسته فضای خالی عنوان دارند و نباید برای کاور رویداد استفاده شوند.

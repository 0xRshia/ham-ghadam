# تغییرات فرانت — ۱۵ اکتبر ۲۰۲۶

این مجموعه پس از ادغام PR شمارهٔ ۳ روی شاخهٔ `frontend-arad` آماده شده است و تغییرات بلیت، خرید، پروفایل برگزارکننده، فیلتر و اعلان را برای بررسی در `main` جمع می‌کند. رابط فارسی، راست‌به‌چپ، تاریخ شمسی و قیمت تومان حفظ شده‌اند.

## بلیت و جریان خرید

- انتخاب تعداد و ردهٔ بلیت در جزئیات رویداد انجام می‌شود؛ ادامهٔ خرید از اطلاعات تماس شروع می‌شود و انتخاب در پیش‌نویس مرورگر، از جمله هنگام ورود مهمان، باقی می‌ماند.
- کنترل مشترک انتخاب، ظرفیت کل و رده، سقف شش بلیت و سقف مبلغ سفارش را بررسی می‌کند؛ ردهٔ غیرفعال قابل خرید نیست. پیش‌نویس نامعتبر به صفحهٔ رویداد برمی‌گردد.
- صفحات تماس، خلاصهٔ سفارش، روش پرداخت، جزئیات بلیت و QR با طرح محصول هماهنگ شده‌اند. قرارداد رزرو و پرداخت فعلی حفظ شده است.

## پروفایل و دنبال‌کردن

- پروفایل عمومی برگزارکننده کاور، آواتار، شمارنده، اشتراک لینک و تب‌های رویداد، مجموعه و درباره دارد. معرفی بلند باز و بسته می‌شود و تصویر غایب یا خراب جایگزین دارد.
- صاحب صفحه لینک ویرایش حساب و مدیریت رویدادها می‌بیند. مهمان برای دنبال‌کردن به ورود با مسیر بازگشت هدایت می‌شود.
- وضعیت دنبال‌کردن در اجزای مرتبط هماهنگ است؛ درخواست تکراری مسدود و خطا کنار همان دکمه نمایش داده می‌شود. صفحهٔ دنبال‌شده‌ها پیشنهاد و نمای کشف دارد.
- زیر کارت‌های کوچک خانه در هر دو چیدمان، کاروسل افقی برگزارکننده‌ها اضافه شده است. «مشاهده همه» نمای کشف را باز می‌کند و مسیر بازگشت پس از ورود را حفظ می‌کند. خود کاربر از پیشنهاد خانه حذف می‌شود و ترتیب پاسخ API حفظ می‌شود.
- کارت تکی مجموعه در پروفایل شخصی وسط‌چین شده است.

## فیلترها و اعلان‌ها

- چیدمان بخش‌های تاریخ، دسته، قیمت و نوع رویداد و دکمهٔ اعمال با مرجع محصول هماهنگ شده است. آیکون‌های Vuesax به‌صورت فایل محلی با مستند منبع و مجوز استفاده شده‌اند.
- اعلان‌ها بر اساس نوع واقعی داده به گروه‌های بلیت، برگزارکننده، مجموعه، رویداد و سایر تفکیک می‌شوند. شمارنده و نشان خوانده‌نشده، خواندن تکی و همگانی و پیوند مقصد مرتبط دارند؛ اعلان خرید مستقیماً بلیت مرتبط را باز می‌کند.
- API افراد، دعوت، پیام‌رسانی، نشان تأیید، شبکه‌های اجتماعی یا آپلود مستقل کاور اضافه نشده است.

## اعتبارسنجی و محدودیت‌ها

- TypeScript و ساخت Node موفق‌اند؛ ۱۱۸ پیوند stylesheet/module preload با خروجی تولید تطبیق دارند.
- ESLint صفر خطا و ۳۱ هشدار موجود دربارهٔ `img` دارد. آزمون انتخاب بلیت و مسیرهای ورود، دسته‌بندی و مقصد اعلان‌ها و مستندات/OpenAPI موفق‌اند.
- بررسی مرورگر مراحل خرید، پروفایل و دنبال‌کردن در کار قبلی این مجموعه ثبت شده است. فیلتر، وسط‌چینی مجموعه، گروه‌بندی و خواندن اعلان‌ها و کاروسل خانه نیز روی localhost بررسی شدند. دنبال‌کردن/لغو و ورود از «مشاهده همه» در نمای کنترل‌شدهٔ خانه تأیید شدند.
- دیتای فعلی محلی برگزارکنندهٔ عمومی ندارد؛ حالت پُر پروفایل و کاروسل با پاسخ موقت API آزموده شد. این پاسخ‌های آزمایشی وارد کد محصول یا دیتابیس نشده‌اند. محدودیت فعلی نمایش پروفایل پس از اولین رویداد منتشرشدهٔ غیرنمونه و سقف ۱۰۰ برگزارکنندهٔ API حفظ شده است.
- این بررسی تأیید پرداخت واقعی، پیامک، ایمیل، Push، دوربین یا همهٔ دستگاه‌ها نیست. API، schema و migration تغییر نکرده‌اند. فایل‌های env، کلیدها، دیتابیس، خروجی ساخت و اسکرین‌شات‌های محلی وارد Git نمی‌شوند.

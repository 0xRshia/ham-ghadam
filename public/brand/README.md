# نشان هم‌قدم

منابع: فایل‌های SVG تحویلی کارفرما در ۲۳ اکتبر ۲۰۲۶ و دو لوگوی PNG تحویلی در ۲۹ اکتبر ۲۰۲۶.

- `hamghadam-symbol.svg`: فایل اصلی `hm ghadam logo.svg`، نماد سفید شفاف؛ بدون تغییر.
- `hamghadam-wordmark.svg`: فایل `hm ghadam logo type.svg`؛ مسیرها و رنگ دست‌نخورده، viewBox محدود به طرح با حاشیهٔ ۸ واحد.
- `../favicon.svg`: فایل اصلی `s.svg`، نماد سفید روی مربع نارنجی؛ بدون تغییر.
- `../favicon-32x32.png`: خروجی شفاف ۳۲×۳۲ از همان SVG برای مرورگرهای فاقد پشتیبانی SVG.
- `../favicon.ico`: خروجی ۳۲ بیتی با اندازه‌های ۱۶، ۳۲ و ۴۸ پیکسل و قاب‌های bitmap استاندارد برای سازگاری مرورگرها و درخواست مستقیم `/favicon.ico`.
- `hamghadam-logo-white-on-orange.png`: تصویر اصلی سنجاب سفید روی نارنجی، تحویل ۲۹ اکتبر ۲۰۲۶؛ منبع آیکون Home Screen.
- `hamghadam-logo-orange-on-white.png`: تصویر اصلی سنجاب نارنجی روی سفید، تحویل همان روز؛ نسخهٔ جایگزین لوگو.
- `hamghadam-apple-touch-icon-2b04d97f998d.png`: خروجی PNG مات ۱۸۰×۱۸۰ از نسخهٔ سفید روی نارنجی، با حفظ قاب کامل و نسبت تصویر ارسالی؛ بدون گردکردن گوشه‌ها یا افزودن سایه. metadata برنامه، `/docs` و وبلاگ مستقل همین مسیر را معرفی می‌کنند.
- `../apple-touch-icon.png`: همان خروجی جدید برای درخواست پیش‌فرض Safari از ریشهٔ سایت.

رنگ اصلی فایل‌های SVG نارنجی `#F07F46` است. PNGهای جدید با رنگ و هندسهٔ ارسالی حفظ شده‌اند؛ لوگو با CSS یا بازطراحی جایگزین نشده است.

خروجی‌های favicon PNG و ICO در ۲۵ اکتبر ۲۰۲۶ با Sharp از `favicon.svg` و با حفظ نسبت تصویر ساخته شده‌اند. شناسهٔ نسخهٔ faviconها، `456303c4dc5b`، دوازده نویسهٔ اول SHA-256 فایل اصلی SVG است.

آیکون Home Screen در ۲۹ اکتبر ۲۰۲۶ از PNG جدید با Sharp و `resize(180, 180, { fit: "contain" }).removeAlpha().png()` ساخته شد؛ شناسهٔ `2b04d97f998d` دوازده نویسهٔ اول SHA-256 خروجی PNG است. نسخه در **نام فایل** قرار دارد تا نشانی فایل قبلی استفاده نشود. هنگام تعویض تصویر، خروجی و نام نسخه‌دار، نسخهٔ ریشه و سه ارجاع بالا را با هم به‌روز کنید. آماده‌سازی دارایی وبلاگ هر دو مسیر را از `public/` کپی می‌کند. بررسی نهایی Add to Home Screen باید روی آیفون واقعی و پس از استقرار انجام شود؛ آزمون مرورگر دسکتاپ این پنجرهٔ iOS را شبیه‌سازی نمی‌کند.

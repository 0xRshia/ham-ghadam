# قلم درباره

فایل `darbareh-variable.woff2` بدون تبدیل یا ویرایش از مسیر `Darbareh Pro/Webfonts/Variable Font WebFonts/darbarehVFWebVF.woff2` در بستهٔ `Darbareh Pro (1).zip` ارسالی کاربر استخراج شده است.

- خانواده: Darbareh، طراحی Naser Khadem، ناشر Fontiran.
- قالب: WOFF2 متغیر، محور `wght` از ۲۰۰ تا ۹۰۰.
- نسخهٔ استاندارد دارای حروف فارسی و لاتین؛ نسخهٔ تبدیل ارقام لاتین به فارسی استفاده نشده است.
- طبق اطلاعات بسته، فونت تجاری و مالکیتی است؛ مجوز متن‌باز برای آن اعلام نمی‌شود. اسناد مجوز و راهنمای اصلی در بستهٔ ارسالی حفظ شده‌اند.

نام خانواده در CSS برنامه `Darbareh` است. این فایل یک‌بار از layout اصلی preload می‌شود و متغیر `--font-app` مرجع رابط است.
